Como integrar um sistema

Qualquer sistema que faça uma chamada HTTP integra com o Valida SETIC, em qualquer linguagem e sem biblioteca nova. Não é preciso reescrever o sistema: só chamar a API antes de gravar.

  1. Antes de gravar, envie os dados para POST /validar, dizendo qual sistema é você (sistema_origem).
  2. Bloqueado ("valido": false): mostre ao usuário cada erro embaixo do campo (campo e mensagem) e não grave.
  3. Aprovado ("valido": true): grave no seu banco os dados_padronizados, já no formato padrão.

O que muda no sistema

          
Um cadastro em PHP que já grava no banco. Para passar a validar, entram 9 linhas antes do insert, que bloqueiam o dado errado, e 3 linhas passam a gravar o dado padronizado. Nada mais no sistema muda.

        

        

          

            
Antes: grava o que o usuário digitou

            
// o sistema já tem os dados e vai gravar$sql->insert('cidadao', [    'nome' => $nome,    'cpf' => $cpf,    'nascimento' => $nascimento,]);

          

          

            
Depois: +9 linhas e 3 alteradas

            
// o sistema já tem os dados e vai gravar$resposta = valida_setic([    'nome' => $nome,    'cpf' => $cpf,    'data_nascimento' => $nascimento,]);if (!$resposta['valido']) {    return mostrar_erros($resposta['erros']);}$d = $resposta['dados_padronizados'];$sql->insert('cidadao', [    'nome' => $d['nome'],    'cpf' => $d['cpf'],    'nascimento' => $d['data_nascimento'],]);

          

        

        
    
          
  • ~10 linhas por formulário: valida_setic() é o exemplo PHP acima, colado uma vez no sistema.
