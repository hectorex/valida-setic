Valida SETIC

Os sistemas chamam a API antes de gravar: o dado é verificado e padronizado, ou bloqueado com o motivo.

Sistema A Cadastro de cidadão que valida os dados na API antes de gravar no próprio banco. Sistema B Outro sistema, com campos diferentes, que obedece às mesmas regras sem mudar o código. Gestão de Regras (CAGD) Define quais campos são obrigatórios ou ativos para todos os sistemas e acompanha o painel de erros. Como integrar O mesmo exemplo em curl, Python, JavaScript, PHP, Java e C#: qualquer sistema integra em poucas linhas. Documentação da API Swagger com exemplos de entrada e saída de cada rota.
